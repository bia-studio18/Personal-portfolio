# Tasbiha Shahzaib — Personal Portfolio

A clean, modern, and fully responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Features

- Fully responsive design (Desktop, Tablet, Mobile)
- Dark / Light mode toggle (saves preference)
- Smooth scroll & animations (AOS)
- Typing effect in hero section
- Contact form powered by EmailJS
- GitHub stats integration
- Professional single-page layout

## Sections

1. **Hero** — Introduction & call-to-action
2. **About** — Personal background
3. **Skills** — Technical skills with progress bars
4. **Projects** — Featured work
5. **GitHub** — Activity & contribution graph
6. **Contact** — Form + social links

## Tech Stack

- HTML5
- CSS3 (Custom properties, Flexbox, Grid)
- JavaScript (Vanilla)
- Typed.js
- AOS (Animate On Scroll)
- EmailJS
- Font Awesome
- Google Fonts (Poppins)

## How to Run

1. Download or clone the repository
2. Open `index.html` in any modern browser
3. No build step required
