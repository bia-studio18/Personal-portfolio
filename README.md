# Tasbiha Shahzaib — Personal Portfolio

A clean, modern, and fully responsive personal portfolio with a warm **Burgundy + Brown** theme.

**Live Demo:** [https://bia-studio18.github.io/Personal-portfolio/](https://bia-studio18.github.io/Personal-portfolio/)

---

### Features

- Warm Burgundy & Brown color theme
- Dark / Light mode toggle (saves preference)
- Smooth scroll & AOS animations
- Typing effect in hero section
- Fully responsive (Desktop → Tablet → Mobile)
- Contact form (EmailJS)
- Updated project showcase including:
  - Aether Dashboard
  - SHOEPHILE
  - Little Space Explorer
  - Hermes
  - Weather App

---

### Tech Stack

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript
- Typed.js
- AOS (Animate On Scroll)
- EmailJS
- Font Awesome
- Google Fonts (Poppins)

---

### How to Run

1. Clone or download this repository
2. Open `index.html` in any modern browser
3. No build step required
